MBTI

Plug-and-play cross-class separation for fine-grained diffusion personalization

Youngjae Choi*, Heewon Kim†
*First author  ·  †Corresponding author
Paper Code

Abstract

MBTI is a plug-and-play enhancement for diffusion personalization that improves fine-grained concept learning. It promotes cross-class separation in the text-embedding space to preserve class-specific details and improve downstream few-shot performance.

Method

SES

Select Top-K most confusing neighbor class embeddings.

DMM

Maximize diffusion-based distance via predicted-noise differences under the same zt.

Objective

Balance separation with denoising fidelity using time-adaptive regularization.

Qualitative Results

MBTI produces sharper, more class-consistent fine-grained images, preserving key structures that baselines and SoTA methods often blur or distort.

Quantitative Results

MBTI achieves higher few-shot Macro-ACC across fine-grained datasets and improves FID/CLIP when added to LoRA and DreamBooth+LoRA, showing consistent plug-and-play gains.
