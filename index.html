MBTI: Metric-Based Textual Inversion
for Fine-Grained Image Classification

AUTHOR_NAME
AFFILIATION_LINE
2025
Paper Poster Code

MBTI is a plug-and-play enhancement that promotes cross-class separation of class embeddings to preserve fine-grained details.

Plug-and-play cross-class separation improves fine-grained generation and few-shot classification.

Abstract

Few-shot personalization for fine-grained classes often suffers from detail drift and class confusion. We introduce MBTI, a plug-and-play enhancement that promotes cross-class separation in the text-embedding space. MBTI selects confusing neighbor class embeddings (SES), measures diffusion-based distances via predicted noise differences (DMM), and stabilizes optimization with a time-adaptive regularizer. MBTI improves fine-grained generation quality and boosts few-shot classification performance under augmentation-for-classification across multiple benchmarks.

Method (MBTI)

(a) Support Embedding Selection (SES)

Select Top-K most similar prior class embeddings as supports.

(b) Distance Metric Module (DMM)

Measure cross-class distance using predicted-noise differences under the same diffusion state.

Training Objective

Optimize the class embedding with a balanced loss (separation + stability).

Results

Qualitative Comparison

MBTI preserves fine-grained details where baselines often fail.

SoTA Comparison

Compared to SoTA methods, MBTI preserves fine-grained details more reliably.

Quantitative Evaluation

MBTI improves few-shot Macro-ACC across fine-grained datasets.

MBTI acts as a plug-and-play enhancement and improves FID/CLIP when added to existing methods.
